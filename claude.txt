Here's the script. The key design decisions:

- **`nltk`** for lemmatization (WordNetLemmatizer) — this is the standard NLP library for this kind of task. It reduces words to their root/lemma form (e.g. "rapacious" stays, "birds" → "bird", "curved" → "curve").
- **Parsing**: Each line's format is `Word (pos.) Definition text.` — the script strips the part-of-speech tag in parentheses, then tokenizes and lemmatizes the definition words.
- **Output**: Both `pickle` (fast, exact recovery) and `json` (human-readable) are saved.
- **Coverage gap**: Lemmatization won't guarantee 100% of definition words appear as dictionary keys — that's a property of the dictionary's own completeness, not fixable in parsing. But every word will be in its most "root" form.**Setup — run once after downloading:**
```bash
pip install nltk
python -c "import nltk; nltk.download('wordnet'); nltk.download('averaged_perceptron_tagger_eng'); nltk.download('punkt_tab')"
```

**Run:**
```bash
python parse_dictionary.py dictionary.txt
# produces: dictionary_parsed.pkl  and  dictionary_parsed.json
```

**Recover later:**
```python
import pickle
with open("dictionary_parsed.pkl", "rb") as f:
    d = pickle.load(f)
d["accidentally"]  # → ['accidental', 'by', 'casualty', 'chance', 'essentially', ...]
```

**Key design notes:**

- **Lemmatization with POS context** — each token is POS-tagged first (noun/verb/adj/adv), then lemmatized accordingly. This gives more accurate roots than lemmatizing blindly (e.g. "curved" → "curve" as a verb vs "curve" as a noun both work correctly).
- **POS codes stripped** — the `(n.)`, `(adv.)`, `(n. pl.)` etc. are removed before any word extraction.
- **Multi-line merging** — entries like the two `Accipiter` lines are merged into one key with a unified, deduplicated word set.
- **Both pickle and JSON saved** — pickle for fast exact recovery in Python, JSON as a human-readable backup.
- **Coverage caveat**: lemmatization gets you very close, but 100% of definition words appearing as headwords is a property of the dictionary's own completeness — some words (like "the", "of", or rare words) simply won't be headwords no matter what normalization you apply.
